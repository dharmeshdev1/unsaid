    How it finds things without reading your question

    1. Your device turns the question into numbers and picks a few likely groups of documents, using a public map it downloaded once.
    2. It encrypts those numbers with a key used once. The server multiplies its whole index by the result, so every document is touched equally, and returns scores it cannot read.
    3. Your device decrypts the scores and asks for the best documents the same way, in the same encrypted form.
    4. Your device decrypts the documents and checks them. To the server, every search is the same two requests of noise.

    What this does not hide

    The server still sees your IP address, when you search and how often. A VPN or Tor hides the address, but not the timing. The lattice encryption has not had an independent audit yet, so please read the security notes before relying on it.
